# Virtual Life - Stage 2 (Player, Camera, Mobile Controls)
1. Copy Assets/VirtualLife over your project (adds new files; 2 Stage 1 editor/core files are modified - see report).
2. Wait for compile, then: Tools > VirtualLife > Stage 2 > Run Setup  (open scene is saved first; CommunityOne is modified).
3. Play from the Bootstrap scene (not CommunityOne directly) -> ENTER WORLD.
4. To test mobile UI on PC: Bootstrap > GameBootstrapper > Platform Override = Android, or tick Force Show In Editor on MobileControlsUI.
