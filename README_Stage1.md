# Virtual Life - Stage 1 (Foundation)
1. Unity 2022.3 LTS or Unity 6, with Input System (com.unity.inputsystem) and uGUI installed. URP recommended.
2. Project Settings > Player > Active Input Handling = "Input System Package (New)" (or Both).
3. Copy the Assets/VirtualLife folder into your project's Assets folder.
4. Menu: Tools > VirtualLife > Stage 1 > Run Setup (creates folders, input actions, scenes, Build Settings entries; never overwrites).
5. Open Scenes/Bootstrap and press Play.
